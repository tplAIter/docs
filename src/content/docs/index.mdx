## A deliberate workflow

Describe an outcome, select reusable template blocks, render a project shape, and validate the result. The goal is to make the path from request to generated code easier to inspect and review.

## What this site documents

The documentation describes the current public checkpoint, including its limits. MCP is the intended selection interface, while live lifecycle support is still being completed. The Go engine remains the template runtime; this site does not introduce another rendering engine.

:::note
Claims about token savings, reliability, or maintainability need a defined evaluation. They are not presented here as measured results.
:::
