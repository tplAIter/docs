# tplAIter documentation

This is the private, unreleased documentation site for tplAIter. It is an independent presentation layer and does not change the Go engine. There is no public deployment, tagged release, or compatibility promise yet.

## Local development

Requires Node.js 20 or newer.

```sh
npm ci
npm run dev
```

The production checks are:

```sh
npm run lint
npm run build
npm audit
```

The repository is intentionally private while publication and licensing decisions are pending. Do not treat the private checkpoint as a public installation source.
